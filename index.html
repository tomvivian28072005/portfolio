TIPE – Désaturation de Roue de réaction

Déc. 2024 – Juil. 2025

Étude d'un système de contrôle d'orientation de nanosatellite.

Analyse Physique

Contexte : Les perturbations orbitales saturent les roues de réaction — sans carburant, les nanosatellites doivent exploiter le champ magnétique terrestre pour désaturer tout en maintenant leur attitude.

Action : Modélisation de la conservation du moment cinétique et de l'interaction champ magnétique terrestre / bobines du satellite.

Compétences : Mécanique du solide · Électromagnétisme · Moments cinétiques

Simulation Numérique — Python

Action : Développement d'un programme Python calculant le couple de chaque magnéto-coupleur pour désaturer les roues en maintenant l'attitude du satellite.

Impact : Viabilité des magnéto-coupleurs démontrée · limites selon l'orbite identifiées · note 15,2/20 au concours CCINP.

Compétences : Python · Analyse numérique · Gestion de projet
